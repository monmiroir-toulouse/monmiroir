Cliquez **Add branch protection rule** 4. Dans **Branch name pattern** : tapez `main` 5. Cochez les options suivantes : ``` ✅ Require a pull request before merging ✅ Require approvals (minimum : 1) ✅ Dismiss stale pull request approvals when new commits are pushed ✅ Require status checks to pass before merging ✅ Require branches to be up to date before merging ✅ Include administrators ✅ Restrict who can push to matching branches ``` 6. Cliquez **Create** ou **Save changes** > ✅ Résultat : Plus personne (même vous) ne peut modifier `main` directement sans revue. --- ## 2. SECRETS — Ne jamais mettre de clé API dans le code ### ❌ Ce qu'il NE FAUT JAMAIS faire ```javascript // DANGEREUX — clé visible dans le code const apiKey = "sk-ant-api03-xxxxxxxxxxxx"; ``` ### ✅ Ce qu'il FAUT faire — Variables d'environnement #### Pour le développement local Créez un fichier `.env` à la racine du projet : ```bash # .env — NE JAMAIS COMMITER CE FICHIER ANTHROPIC_API_KEY=sk-ant-api03-votre-clé-ici INVIDEO_API_KEY=votre-clé-invideo-ici NODE_ENV=development ``` Ajoutez `.env` dans votre `.gitignore` : ```bash # .gitignore .env .env.local .env.production node_modules/ *.log ``` #### Dans votre code Node.js ```javascript // ✅ Utiliser process.env require('dotenv').config(); const apiKey = process.env.ANTHROPIC_API_KEY; const invideoKey = process.env.INVIDEO_API_KEY; if (!apiKey) { throw new Error('❌ ANTHROPIC_API_KEY manquante dans .env'); } ``` #### Sur GitHub Actions (CI/CD) 1. Allez sur votre dépôt → **Settings** → **Secrets and variables** → **Actions** 2. Cliquez **New repository secret** 3. Ajoutez : | Nom du secret | Description | |---|---| | `ANTHROPIC_API_KEY` | Clé API Claude Anthropic | | `INVIDEO_API_KEY` | Clé API InVideo | | `DATABASE_URL` | URL base de données chiffrée | | `JWT_SECRET` | Secret pour les tokens JWT | 4. Dans votre workflow `.github/workflows/deploy.yml` : ```yaml name: Deploy Mon Miroir on: push: branches: [ main ] jobs: deploy: runs-on: ubuntu-latest steps: - uses: actions/checkout@v3 - name: Setup Node.js uses: actions/setup-node@v3 with: node-version: '18' - name: Install dependencies run: npm ci - name: Security audit run: npm audit --audit-level=high - name: Deploy env: ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }} INVIDEO_API_KEY: ${{ secrets.INVIDEO_API_KEY }} JWT_SECRET: ${{ secrets.JWT_SECRET }} run: npm run deploy ``` --- ## 3. PROTECTION SPÉCIFIQUE AUX TÉMOIGNAGES MNA ### Chiffrement des données sensibles ```javascript const crypto = require('crypto'); // Chiffrer un témoignage avant stockage function chiffrerTemoignage(texte, cle) { const iv = crypto.randomBytes(16); const cipher = crypto.createCipheriv( 'aes-256-gcm', Buffer.from(cle, 'hex'), iv ); let chiffre = cipher.update(texte, 'utf8', 'hex'); chiffre += cipher.final('hex'); const authTag = cipher.getAuthTag().toString('hex'); return { iv: iv.toString('hex'), chiffre, authTag }; } // Déchiffrer un témoignage function dechiffrerTemoignage(donnees, cle) { const decipher = crypto.createDecipheriv( 'aes-256-gcm', Buffer.from(cle, 'hex'), Buffer.from(donnees.iv, 'hex') ); decipher.setAuthTag(Buffer.from(donnees.authTag, 'hex')); let texte = decipher.update(donnees.chiffre, 'hex', 'utf8'); texte += decipher.final('utf8'); return texte; } ``` ### Headers de sécurité HTTP ```javascript const helmet = require('helmet'); app.use(helmet({ contentSecurityPolicy: { directives: { defaultSrc: ["'self'"], scriptSrc: ["'self'", "https://api.anthropic.com"], connectSrc: ["'self'", "https://api.anthropic.com"], frameSrc: ["'none'"], objectSrc: ["'none'"] } }, hsts: { maxAge: 31536000, includeSubDomains: true }, noSniff: true, xssFilter: true })); ``` ### Rate limiting — Protéger les endpoints sensibles ```javascript const rateLimit = require('express-rate-limit'); // Limiter les appels à l'API Claude const claudeLimit = rateLimit({ windowMs: 15 * 60 * 1000, // 15 minutes max: 50, // 50 requêtes max message: '⚠️ Trop de requêtes. Réessayez dans 15 minutes.', standardHeaders: true, legacyHeaders: false }); app.use('/api/claude', claudeLimit); // Limiter les tentatives de connexion const loginLimit = rateLimit({ windowMs: 60 * 60 * 1000, // 1 heure max: 10, // 10 tentatives max message: '⚠️ Compte temporairement bloqué.' }); app.use('/api/auth/login', loginLimit); ``` --- ## 5.
